# 🚀 GSoC Help

### Your Roadmap to Google Summer of Code Success 🌟

**Learn from accepted proposals. Discover project ideas. Prepare for your GSoC journey.**

Welcome to **GSoC Help** — a community-driven resource designed to help aspiring contributors navigate their Google Summer of Code (GSoC) journey with confidence.

Finding the right project, understanding what mentors expect, and writing a strong proposal can feel overwhelming, especially when you're applying for the first time.

That's where **GSoC Help** comes in! 💙

Explore accepted proposals from previous years, learn how successful applicants present their ideas, and use those insights to build a stronger, original proposal of your own.

> 💡 You don't have to start from scratch. Learn from experience, improve your approach, and make your next contribution count.

---

## ✨ Why GSoC Help?

A great GSoC proposal is more than just an interesting idea. It demonstrates your understanding of the project, your technical approach, and your ability to plan and communicate effectively.

With GSoC Help, you can:

- 📚 **Learn from Real Examples** — Explore proposals accepted in previous GSoC editions.
- 📝 **Understand Proposal Structure** — See how successful applicants organize their ideas.
- 💻 **Improve Technical Writing** — Learn to explain solutions, approaches, and implementation details.
- 🗓️ **Plan Realistically** — Understand how milestones and project timelines can be presented.
- 🎯 **Discover New Ideas** — Explore projects and organizations that match your interests.
- 🌱 **Grow as a Contributor** — Take your first steps toward becoming an active open-source contributor.

**Our goal is simple:** Make GSoC preparation more accessible, understandable, and less intimidating for everyone.

## 🗂️ Repository Structure

GSoC Help organizes proposals by year and participating organization so you can find relevant examples quickly.

```text
GSoC-Help/
├── 2026/
│   └── Organization Name/
│       └── Accepted/
│           └── project-topic_username.pdf
├── 2025/
│   └── Organization Name/
│       └── Accepted/
│           └── project-topic_username.pdf
├── 2024/
│   └── Organization Name/
│       └── Accepted/
│           └── project-topic_username.pdf
├── 2023/
│   └── Organization Name/
│       └── Accepted/
│           └── project-topic_username.pdf
└── README.md
```

### 📄 Proposal Naming Convention

Please use descriptive filenames to keep the repository organized.

**Recommended format:**

```text
[sub-org-name_]project-topic_username.pdf
```

**Examples:**

```text
2026/Python Software Foundation/Accepted/cpython_asyncio-improvements_johndoe.pdf

2026/OpenVINO Toolkit/Accepted/model-optimization_alexsmith.pdf

2025/TensorFlow/Accepted/keras-cv-enhancements_janedoe.pdf
```

Please place each proposal in the appropriate year, organization, and category directory.

Every meaningful contribution makes GSoC preparation easier for someone else.

### 🚀 How to Contribute

#### Step 1: Fork the Repository

Click the **Fork** button at the top of the GSoC Help GitHub repository.

#### Step 2: Clone Your Fork

Replace `YOUR_USERNAME` with your GitHub username.

```bash
git clone https://github.com/YOUR_USERNAME/GSoC-Help.git
cd GSoC-Help
```

#### Step 3: Configure the Upstream Repository

Add the original GSoC Help repository as an upstream remote.

```bash
git remote add upstream https://github.com/OWNER/GSoC-Help.git
```

Replace `OWNER` with the GitHub username or organization that owns the original repository.

#### Step 4: Create a Branch

```bash
git checkout -b add-proposal-<year>-<org-name>
```

For example:

```bash
git checkout -b add-proposal-2026-python
```

#### Step 5: Add Your Proposal

1. Open the appropriate year directory.
2. Create an organization directory if necessary.
3. Add an `Accepted/` directory if one doesn't already exist.
4. Place your proposal PDF in the correct location.
5. Follow the recommended filename convention.

#### Step 6: Commit Your Changes

```bash
git add .
git commit -m "Add GSoC <year> proposal for <org-name>"
```

#### Step 7: Push Your Branch

```bash
git push origin add-proposal-<year>-<org-name>
```

#### Step 8: Open a Pull Request 🎉

Visit your fork on GitHub, click **Compare & pull request**, and submit your changes for review.

Once your contribution is reviewed and merged, you've helped another aspiring contributor learn from the community!

## ⚠️ Important Guidelines

Please keep GSoC Help useful, respectful, and reliable.

- **Respect authors:** All proposals remain the work of their original authors.
- **Learn, don't plagiarize:** Use existing proposals for inspiration and understanding, not as templates to copy.
- **Verify information:** Make sure submitted proposals are accurately labeled by year and organization.
- **Respect permissions:** Only submit documents you have the right to share, and follow applicable licenses and distribution restrictions.
- **Keep contributions organized:** Follow the repository's directory and naming conventions.
